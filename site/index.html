Inkprint

Turns an Inkplate e-paper board into a network printer: print a page from a phone or computer and it stays on the panel. Firmware @VERSION@, an experimental pre-release.

This browser can't talk to USB serial devices. Use desktop Chrome or Edge, or flash with esptool as described in the release notes.

1. Pick your board

Inkplate 6 untested

ESP32 revision 3.0 or later.

Inkplate 6, early boards tested

ESP32 revision 1. These chips have a PSRAM bug the firmware can't work around: expect occasional corrupted pages or crashes. If the board hangs during a refresh, reset or unplug it, since the panel's high voltage may stay on.

Inkplate 6 v2 untested

ESP32 revision 3.0 or later.

Which Inkplate 6 do I have?

Early Inkplate 6 boards have a revision 1 ESP32. If you're not sure, try the regular Inkplate 6 install first. On a revision 1 chip it won't start: after installing, the log (“Logs & Console” in the installer) shows the bootloader refusing the image because of the chip revision. Then install the early-boards version instead. Nothing is harmed by trying.

2. Install

  1. Connect the board with a USB data cable and switch it on.
  2. Click Install and pick the board's serial port. On Linux you may need to be in the dialout group.
  3. Install erases saved settings. Use Update, keep settings to upgrade a board that is already set up.

3. Set up Wi-Fi

  1. On first start the board opens a Wi-Fi network called Inkprint-xxxx and shows instructions on the panel.
  2. Join it with a phone. The setup page opens (or browse to http://192.168.4.1/setup).
  3. Pick your network, enter its password and a location, and save. The board restarts and appears as a printer named “Inkplate 6 (xxxx)”.
